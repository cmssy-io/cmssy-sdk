# v11 → v12

A media value stops being the asset's address and becomes its identity. The address is materialised when you read it.

## What changed

`fields.media()` used to give you a `string` - the asset's URL, copied into your content. It now reads back as an object:

```ts
{
  id: string;
  url: string | null;
  visibility: "public" | "private";
  alt?: string;
  width?: number;
  height?: number;
}
```

A gallery (`multiple: true`) is an array of the same object.

## Why

Storing the address meant every change to it was a content migration. Moving cmssy's assets to R2 rewrote 218 URLs across six collections to re-key 31 objects; with identities it would have updated 31 rows and touched no content. It also made `visibility` inexpressible, which is what private media needs.

## What you change

```diff
-<img src={content.image} />
+{content.image?.url ? <img src={content.image.url} alt={content.image.alt ?? ""} /> : null}
```

```diff
-{content.gallery.map((url) => <img key={url} src={url} />)}
+{content.gallery.map((one) =>
+  one.url ? <img key={one.id} src={one.url} alt={one.alt ?? ""} /> : null,
+)}
```

**Guard `url`.** It is `null` for a private asset - the consumer obtains a signed address separately - and a reference whose asset was deleted resolves to nothing at all.

**Use `alt`.** It arrives resolved for the locale being read, from the description an editor wrote in the media library. Until now nothing delivered it, so most apps hard-coded an empty string.

**Use `width`/`height`.** They are the intrinsic dimensions, so `next/image` and a plain `<img>` can reserve the right box and stop the layout shifting.

## Help finding the call sites

```
npx cmssy-codemod v12 .
```

It rewrites nothing - a URL read cannot be turned into an object read safely without knowing your markup - but it reports every file with a media field and lists the direct uses it found.

## Model records

`CmssyMedia` in generated model types is the same object, and a single media field is typed `CmssyMedia | null` - a reference whose asset was deleted resolves to nothing, and the type makes you handle it. A gallery drops such entries rather than leaving holes in the array, so its items are never null.

`CmssyFile` is unchanged: a `file` field still holds a string.
